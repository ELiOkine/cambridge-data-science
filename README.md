# Cambridge Data Science projects

Portfolio work from Emmanuel Okine’s Cambridge PACE programme (Data Science with ML and AI). The pieces here are the ones that can be shared publicly.

| Project | Topic | What it shows |
| --- | --- | --- |
| [Marine engine anomaly detection](marine-engine-anomaly-detection/) | Unsupervised anomaly detection on engine telemetry | IQR, One-Class SVM, Isolation Forest, and a consensus rule |
| [E-commerce customer segmentation](ecommerce-customer-segmentation/) | Clustering 68,300 customers | Feature engineering, k selection, K-Means, PCA and t-SNE |

These were completed as coursework. Recruiter-facing write-ups are in each folder. The notebooks are the original analysis, lightly cleaned.

## What is not in this repository

Other PACE projects, including a team employer project, used confidential or licensed data and are not published here.

## Stack

Python, pandas, scikit-learn, matplotlib, seaborn.
